# Resume Tips for AI Engineer Role — Day 78

## What to highlight

### Technical Skills section
- LLMs: Anthropic Claude, prompt engineering, few-shot, chain-of-thought
- RAG: LangChain, ChromaDB, HuggingFace embeddings, hybrid search
- Agents: LangGraph, ReAct pattern, tool creation, multi-agent systems
- Deployment: FastAPI, Docker, Render, API security
- ML: Scikit-learn, XGBoost, fine-tuning, LoRA, HuggingFace

### Projects section — for each project include
- One line problem statement
- Tech stack (specific versions matter)
- One concrete metric (accuracy %, latency ms, cost saving)
- GitHub link

### Experience section
- Use "built", "deployed", "shipped" — not "learned" or "studied"
- Quantify everything: 10 tools, 3 projects, 100 days
- Lead with impact, not process

## What NOT to include
- Udemy/Simplilearn/Great Learning certificates
- "Familiar with" — only claim things you can demo
- Generic descriptions — be specific about what you built

## Cover letter formula
Paragraph 1: The specific role you want and why this company
Paragraph 2: Your most relevant project (1 project, specific metrics)
Paragraph 3: What you would build for them in the first 30 days
